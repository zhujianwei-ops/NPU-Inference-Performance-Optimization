## 目录结构

**本仓库即工作区**：除模型部署（在仓库外执行）外，阶段二 ~ 六的全部产物均落在此目录内。外部路径（CANNBot、模型权重、参考实现等）只读引用，不就地写入。

```
docs/        方案与规范文档
configs/     部署配置快照（部署在仓库外执行，此处仅归档）
bench/       基线采集脚本
results/     基线数据与优化后数据
profiles/    Profiling 采集数据
analysis/    算子画像表与融合候选清单
ops/         自研算子工程
verify/      验证报告
tools/       公共脚本
```
